- `relatorio-plataformas-personal-chef.md` — relatório final com recomendações priorizadas e lacunas.
- `notas/` — notas brutas de cada frente, com URLs das fontes:
  - `marketplaces_globais.md` (Take a Chef, Yhangry, Cozymeal, Thumbtack, BonAppetour)
  - `brasil_latam.md` (concorrentes e preços no Brasil, Floripa)
  - `marmitas_modelos_adjacentes.md` (planos recorrentes, casos de fracasso, Data Sebrae)

Atenção: comissões e números de empresas vêm de páginas públicas e de imprensa, alguns divergem entre fontes (o relatório avisa). Lacunas conhecidas: comissões no Brasil, tamanho do mercado BR, regras sanitárias/fiscais, Ásia e Oriente Médio. Reveja datas antes de usar um número.
